4. Coefficient algorithm for expected mean squares ($E[MS]$)

Matrix built by evaluating each term's subscripts with the rules for fixed and random factors.

Coefficient assignment rules (J. Zubcoff methodology):

  • FIXED subscript: if it is NOT in the row $\rightarrow$ its number of levels ($p, r...$); if it is NESTED (inside the parentheses) $\rightarrow$ 1; if it is in the row but not nested $\rightarrow$ 0.
  • RANDOM subscript: if it is NOT in the row $\rightarrow$ its number of levels ($s, n...$); if it IS in the row $\rightarrow$ 1.

Step-by-step calculation of the MS estimators

Click a row (or use the buttons) to see how its E[MS] is obtained. The table starts with the Residual and moves up, from simplest to most complex. Red columns and lavender rows are the ones left out.

Rules for the MS estimators:

  1. Choose the target row and identify its subscripts. The rows that contain all of those subscripts take part (the rest are discarded), and so do the columns that do NOT contain them.
  2. In each participating row, multiply the visible coefficients by that row's variance (σ², or Φ for a fixed term).
  3. Add up all those components. The variance of the residual is σ²e.

5. Denominators for the $F$ ratio

To test each effect, the denominator is the mean square ($MS$) whose expectation ($E[MS]$) is identical to the numerator's, except for the term being tested. If no single valid denominator exists, "No test" is shown.

6. Ad-hoc design optimization

Methodological strategy to maximize the power of the $F$ test for the contrasts of greatest scientific interest.

Key features

1. Dynamic ad-hoc modelling Flexible factor set-up (fixed/random, orthogonal or nested in multiple combinations) and number of replicates.
2. Clean mathematical syntax Formal linear models without redundant parentheses in fixed interactions (e.g. $P \times R$).
3. E[MS] matrix algorithm Automated structure of expected mean squares: Cornfield-Tukey algorithm under the restricted mixed model assumption.
4. Denominator evaluation Strict comparison of variance components in $E[MS]$ to find exact denominators (or flag "No test").
